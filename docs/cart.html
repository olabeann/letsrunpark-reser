DEVELOPER POLICY · Alt+P

서비스 정책 · FE · BE

현재 화면의 운영 기준, 화면 동작과 서버 검증 규칙을 함께 표시합니다.

회원

  • 네이버·카카오 로그인만 제공하며 비회원 예약은 허용하지 않습니다.
  • 로그인 제공자가 다르면 별도 계정으로 식별하고 계정 통합은 제공하지 않습니다.
  • 한 계정으로 여러 어린이의 티켓을 예약할 수 있습니다.

프로그램·회차 구조

  • 프로그램을 먼저 등록하고 그 하위에 반복 회차를 등록합니다.
  • 프로그램에는 지역·부서·유형·명칭·기본 가격·운영 일정·노출 기간·판매 기간·취소 가능 시간·할인을 저장합니다.
  • 회차에는 시작·종료 시간, 온라인 판매 수량, 판매 상태만 저장합니다.
  • 회차명은 시간순으로 자동 생성하며 사용자 안내문과 현장 판매 수량은 입력받지 않습니다.
  • 현장 키오스크는 API 미연동이므로 온라인 관리자에서 현장 재고를 관리하지 않습니다.

예약·재고

  • 프로그램별로 계정당 이용일 하루 최대 구매 수량을 설정하며 기본값은 4매이며 회차 잔여 수량도 함께 적용합니다.
  • 같은 프로그램의 같은 회차는 여러 매 구매할 수 있지만, 다른 프로그램의 이용 시간이 기존 유효 예약 또는 장바구니와 겹치면 담을 수 없습니다.
  • 한 장바구니에는 동일 이용일·지역·담당부서의 회차만 담을 수 있습니다.
  • 장바구니는 재고를 미리 점유하지 않으며, 같은 회차를 여러 사용자가 동시에 담아도 결제 전까지는 서로 막지 않습니다.
  • 결제는 먼저 완료한 순서대로 확정되며, 몇 초 차이로 결제가 밀린 사용자에게는 "이미 결제가 완료된 회차입니다."라고 안내합니다.
  • 결제 직전에 재고·구매 한도·할인 사용량을 서버에서 다시 검증합니다.

할인·취소

  • 할인은 정책별 이용일 한도를 적용하며 환불 완료 시 취소 티켓 수만큼 한도를 복원합니다.
  • 온라인 할인 증빙 기능은 제공하지 않습니다.
  • 부분취소는 선택 티켓에 저장된 실제 결제액을 그대로 환불해 재계산·원 단위 반올림하지 않습니다.
  • 사용자 취소 마감은 프로그램별로 관리자가 설정합니다.
  • 회차 종료 시 입장 확인 없이 이용 완료 처리하며 입장 여부와 노쇼는 별도 관리하지 않습니다.

계정·권한

  • 통합 관리자와 담당 부서별 공용 계정을 발급합니다.
  • 부서 계정은 자기 부서의 프로그램·회차를 관리하고 다른 부서 프로그램은 조회만 가능합니다.
  • 예약·취소·환불·정산은 계정에 연결된 담당 부서 데이터에만 접근할 수 있습니다.
  • 통합 관리자는 모든 지역·부서 관리와 부서 계정 발급·중지·비밀번호 재발급이 가능합니다.
  • 임시 비밀번호는 안전하게 생성해 최초 전달 후 원문을 다시 노출하지 않으며 분실 시 재발급합니다.
  • 모든 서버 API에서 로그인 계정의 소속 지역·부서와 요청 대상의 지역·부서를 검증합니다.

티켓·정산

  • 결제 1건에는 예약번호를 하나만 발급하고 상품·회차는 예약 아래 티켓으로 구분합니다.
  • 같은 프로그램·같은 시간대의 복수 인원은 한 티켓에 인원수로 표시합니다.
  • 다른 프로그램 또는 다른 시간대는 별도 티켓으로 표시합니다.
  • 예약에는 결제 시점의 프로그램명·가격·할인 정보를 스냅샷으로 보관합니다.
  • 정산은 서비스 제공 완료일 기준이며 지역·부서·프로그램별로 구분합니다.
